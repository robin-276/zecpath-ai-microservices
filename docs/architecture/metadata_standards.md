# Standardized Metadata Schema

To ensure data traceability and version control across all microservices, every JSON payload generated by the Zecpath platform MUST include a standard `_metadata` block.

## JSON Schema Example

```json
{
  "_metadata": {
    "candidate_id": "cnd-1234-abcd",
    "job_id": "job-9876-wxyz",
    "processing_timestamp": "2026-08-03T11:46:02Z",
    "model_version": {
      "extractor": "v1.0.2",
      "ats_engine": "v2.1.0"
    },
    "environment": "production"
  }
}
```
